# Phase 02 Forest Cabin Direction

Locked on 2026-06-01.

## Approved Direction

- Mood: wooden cabin in a lush green forest, specifically a sunlit clearing.
- Interpretation: atmosphere-first, not literal rustic theming.
- Card treatment: carved objects with spring-lift selection motion.
- Layout intent: scene-based flow instead of a persistent split-screen setup.

## Artifact

- Approved palette board: `forest-cabin-palette-approved.png`

## Palette Notes

- Backgrounds should stay in forest-shadow greens and bark neutrals rather than black.
- Primary interaction color should read as fresh leaf green, not neon.
- Warm wood surfaces should hold the main scene containers.
- Amber should act as daylight and warmth, not as a metallic luxury cue.
- Creek-blue is optional and should stay sparse, only where a cooler contrast note helps.

## Implementation Cues

- Keep the overall UI lighter and more breathable than the earlier dark lounge and apartment directions.
- Avoid pastel treatment, camping clichés, and generic cozy beige.
- Let the forest influence show up through light, framing, and material feel more than through literal illustration.
